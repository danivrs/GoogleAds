# 📊 Google Ads Dashboard

Este proyecto consiste en explorar y analizar una serie de datos del departamento de Marketing de la empresa DH-Consulting. Se desea conocer la evolución de las campañas de Google Ads entre los años 2021 y 2024. Para ello nos han solicitado el desarrollo de un modelo de datos y dashboard interactivo en Power BI Desktop. El objetivo principal es ofrecer una visualización clara y detallada del rendimiento de las campañas según las diferenetes dimensiones.

---

## 📁 Contenido del repositorio

- `/data`: Datos originales xlsx.
- `/dashboard`: Archivo .pbix de Power BI con el modelo completo.
- `/screenshots`: Imágenes del dashboard final.
- `README.md`: Este archivo.

---

## 🧠 Objetivos del proyecto

- Procesamiento, limpieza, transformacion y validación del dataset.
- Modelado de los datos en una arquitectura de estrella (modelo dimensional).
- Creación de tablas de hechos y dimensiones correctamente relacionadas.
- Calculo de métricas clave de performance (CPC, CTR, CPV, CPM, CR, etc.).
- Desarrollo de visualizaciones dinámicas y útiles para la toma de decisiones.

---

## 🔧 Herramientas utilizadas

- **Power BI Desktop**
- **Power Query**
- **Lenguaje DAX**
- **Lenguaje M**
- **Modelado de datos (Estrella)**

---

## 🧮 Métricas implementadas

- Total de clics
- Total de visualizaciones
- Total de impresiones
- Total de gasto
- CPC (Costo por clic)
- CPM (Costo por mil impresiones)
- CTR (Click Through Rate)
- CPV (Costo por visualización)
- Conversion Rate (CR)

---

## 🧱 Modelo de datos

El modelo se estructura en una tabla de hechos principal (`Fact_Ads`) y varias tablas de dimensiones:

- `Dim_Fecha`: Tabla Calendario.
- `Dim_Campaña`: Información sobre campañas.
- `Dim_Audiencia`: Segmentos demográficos y dispositivos.
- `Dim_Conversión`: Categorías y tipos de conversión.

---

## 📊 Visualizaciones desarrolladas

- Gráficos de área para evolución temporal de KPIs.
- Gráficos de barras apiladas por tipo de campaña o país.
- Gráfico de anillo para distribución de conversiones.
- Paneles de filtro (segmentación por campaña, año, país).
- Marcadores y botones para navegación entre vistas.
